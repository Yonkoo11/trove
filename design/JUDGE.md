# Judge

Mode: hackathon
Event: Zecathon (Private Markets track)
Event URL: https://thezecathon.com/

## Criteria

> Does it actually preserve privacy, or does it only look like it does? Leaks are disqualifying, not deductions.
source: https://thezecathon.com/darkpool/data.js

Sponsor tech: Zcash shielded Orchard/Ironwood pool with a FROST 2-of-3 spend key (the vault) doing the custody.
Sponsor screen: the receipt panel on screen one listing the public fields of the real lock transaction, with the fee as the only value and 0 transparent inputs and outputs.
Time budget: 2 minutes (the length of the required submission video)
Time budget source: https://thezecathon.com/
Judges see it on: video at 1280x720 and the live link on a laptop
First 60 seconds: A judge sees that a borrower's ZEC collateral sits in a shielded vault where a public viewer sees only the fee, that three real loan endings paid out correctly on a test chain, and the list of what is still public.
